# rulegenix

Prototype rules generator

## Goal

The intent of this project is to create a research agent that is able to:

- Search for information on a migration topic
- Read the information and extract relevant information
- Consolidate information from multiple sources into a graph database while aggregating related information for a specific migration issue together
- Generate Konveyor analysis rules for each migration issue

## Background

- I am using the [data-enrichment](https://github.com/langchain-ai/data-enrichment-js) example from langgraph.js as a starting point to form this agent
